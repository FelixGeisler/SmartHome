= 4. Solution Strategy

[cols="1,3",options="header"]
|===
| Goal | Approach
| Extensibility | *Ports and adapters.* A `DeviceAdapter` port abstracts a device technology; a registry routes to the adapter by type. A new technology is one new `@Component` (xref:adr/0004-device-integration-model.adoc[ADR 4]).
| Maintainability | *Layering* (Controller -> Service -> Repository) plus the quality gate (Checkstyle / PMD / SpotBugs / JaCoCo).
| Reliability | Bounded connect/read timeouts on the outbound HTTP client.
| Correctness | Behavior is covered by tests, and exceptions map to predictable error responses.
|===
