[cols="1,2,2",options="header"]
|===
| Partner | Sends | Receives
| API client | Registrations, commands, prompts | Device views, state, assistant replies, problem responses
| Smart device | State | Commands
| MQTT broker | Sensor readings (published by sensor nodes) | Nothing
| Solar inverter | Sensor readings (polled over Modbus) | Nothing
| Claude API | Assistant replies, tool calls | Prompts, tool results
|===

== Scope

Register, list, read, and command devices. Around that core the hub ingests sensor readings,
records their history for charts, and exposes the same device operations to the AI assistant.
