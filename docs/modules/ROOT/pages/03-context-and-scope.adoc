== Scope

Register, list, read, and command devices — what a device can do follows from its capabilities
(see xref:adr/0002-capability-based-device-state.adoc[ADR 2]). Around that core the hub ingests
sensor readings, streams them out for history, and exposes the same operations to an AI
assistant.
